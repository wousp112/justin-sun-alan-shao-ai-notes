# 孙宇晨 × 邵艾伦：AI 访谈笔记

[English](README.md)

这份笔记把孙宇晨与[邵艾伦（Alan Shao）](https://x.com/AlanShao111)的四小时对谈，整理成你能和自己的 Agent 一起检验的具体选择。

## 快速开始

1. 打开 [AGENT.md](AGENT.md)，复制整个文件。
2. 粘贴到一个新的 Claude、ChatGPT、Codex 或其他 Agent 会话，再补上你的职业、学习或商业问题。
3. 得到选项比较、一个可以执行的小测试，以及哪些证据会改变建议。

**[复制给你的 Agent → AGENT.md](AGENT.md)**  
在 GitHub 上点击 **Copy raw file**，或打开 **Raw** 后复制全文。提示词已包含必要的访谈内容，不需要另外上传文件。你可以让 Agent 用中文回答。

## 谁适合用

适合想把访谈观点用于实际选择的人，例如决定学什么、搭建哪种 AI 工作方式，或先探索哪个机会。

来源是孙宇晨与**邵艾伦（Alan Shao）**的《对话孙宇晨：年轻人如何抓住AI时代的机会？》，全长约四小时二十二分钟。

笔记整理了如何让 AI 使用长期积累的信息、如何在决定前建立比较基础，以及如何把经历变成有用的产出。孙宇晨表达得很强烈的主张和仍未确定的看法，也保留了各自的语境。

## 使用示例

粘贴 AGENT.md 后，接着写：

> 我在做财务工作，想探索 AI 产品岗位。每周能投入五小时，目前不想辞职。请比较我能先测试的路径，再给一个起步动作。请用中文回答。

Agent 应根据你的条件比较路径，提出一个具体产出，并说明什么结果支持继续或换方向。这份行动方案属于笔记的应用，不代表访谈中已经给过同样的建议。
