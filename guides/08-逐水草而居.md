# 08 逐水草而居

> 「逐水草而居。是什么意思呢？就是哪里有水哪里有草，我们就去哪住。」
> —— 孙宇晨 [01:22:47](https://www.youtube.com/watch?v=0Z-vhBvBmUY&t=4967s)

孙宇晨举了个例子。明天 OpenAI 说录取你，让你去旧金山，你回一句「我在北京买了房，能不能在北京工作」，大概率这个机会就没了（[01:27:43](https://www.youtube.com/watch?v=0Z-vhBvBmUY&t=5263s)）。

当然，每个人走不走得开，情况差很多，有家人，有签证，有房子。这一篇先帮你搞清楚，你要的机会大多在哪，去那里要付出什么代价。去不去，你自己定。

## 怎么做

1. 写下你想要的「水草」是什么，什么岗位，多少收入，想学到什么。
2. 让 AI 列出这类机会最集中的几个城市，再加上能远程做的方式。
3. 定几个你最在乎的指标，比如岗位多不多、收入、学习机会、签证难不难、生活成本，让 AI 拿这些指标把城市排一排。
4. 在排前面的城市里，各找一两个干这行的人聊一聊。
5. 投几份远程或者当地的岗位，看看能不能拿到面试。
6. 心里有了首选，可以安排一次短期试住，亲眼看看。

## 让 AI 帮你搭

```
帮我画一张"水草地图"。
1. 先问我做什么工作、想要什么机会、现在在哪、有什么走不开的（家人、房子、签证）。
2. 联网找这类机会最集中的 5 个城市，加上能远程做的方式。
3. 用这些指标做对比表：岗位数量、薪资、学习机会、签证或落户难度、生活成本。每个数据附来源链接。
4. 推荐前 3 名，每个告诉我去哪里能找到当地从业者聊聊。
5. 为第 1 名设计一个短期试住计划。
存成 水草地图/【日期】.md。
```
