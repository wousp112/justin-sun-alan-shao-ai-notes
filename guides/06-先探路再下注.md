# 06 先探路，再下注：用 AI 做一次像样的决定

> 「不要作决定，看 100 套房……你要买车，你先看 100 辆车。」
> 「探完图再做决定。」
> —— 孙宇晨 [00:40:33](https://www.youtube.com/watch?v=0Z-vhBvBmUY&t=2433s)

## 做完你会得到

一个决定的完整档案：10 个候选 → 3 个入围 → 1 个小实验 → 结论。找工作、选工具、选城市、买东西都能用。

## 为什么这么做

只看过两三个选项，你根本判断不了眼前这个好不好。以前多看要花大量时间，现在 AI 几分钟就能帮你把候选找全、按同一个标准排好。

## 15 分钟上手

1. 写下你正在纠结的一件事，写成一句话，比如：「下个月学哪个 AI 工具最值」。
2. 先写 3 个你最在乎的标准，比如：价格、上手难度、对工作有没有用。**先写标准，再看选项**，不然你会为了喜欢的选项改标准。
3. 让 AI 找 10 个候选，每个都附来源链接。
4. 让 AI 按你的 3 个标准打成一张表。

## 完整版：10 → 3 → 1

| 步骤 | 做什么 |
| --- | --- |
| 找 10 个 | AI 搜索，每个候选附链接、价格、缺点 |
| 选 3 个 | 按你的标准排序，前 3 名进下一轮 |
| 问 3 个模型 | 把这 3 个分别丢给 Claude、ChatGPT、Kimi，问「你会选哪个，为什么」。孙宇晨的原话是：「你可以问一下Claude，问一下……OpenAI o1，问一下比如GLM，三个，可以了。」（[00:18:10](https://www.youtube.com/watch?v=0Z-vhBvBmUY&t=1090s)） |
| 做 1 个小实验 | 对第 1 名做一次能撤回的尝试：试用、约人聊 20 分钟、做一个小样品 |
| 定结论 | 实验结果达标就加码，不达标就换第 2 名 |

## 工具

| 用途 | 推荐 | 国内直接用 |
| --- | --- | --- |
| 找候选、带来源 | [Perplexity](https://www.perplexity.ai) | [秘塔 AI 搜索](https://metaso.cn) |
| 把资料放一起比 | [NotebookLM](https://notebooklm.google) | Kimi 长文本 |
| 对比表 | [Airtable](https://www.airtable.com) | 飞书多维表格 |
| 多模型一起问 | [ChatHub](https://chathub.gg) | 分别打开 Kimi、通义、智谱 |
| 收集别人意见 | [Typeform](https://www.typeform.com) | 腾讯问卷、问卷星 |

## 丢给 Agent 的话

```
帮我做一个决定。我纠结的事情是：【写在这里】。
1. 先问我最在乎的 3 个标准，以及时间和预算上限。
2. 联网找 10 个候选，每个写：链接、价格、优点、缺点、还不确定的地方。
3. 按我的标准做对比表，选出前 3 名。
4. 给第 1 名设计一个 1 周内能完成、能撤回的小实验：具体做什么、看到什么结果就继续、看到什么结果就换。
5. 把以上全部存成 决策/【日期-主题】.md，实验做完我会回来补结果。
```
