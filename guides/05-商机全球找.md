# 05 商机全球找，一周找出一个海外真需求

> 「商机一定要全球性发现……你把全世界的人当做你的客户……商业首先最基本的，就是你要看你有没有创造价值。」
> —— 孙宇晨 [00:32:40](https://www.youtube.com/watch?v=0Z-vhBvBmUY&t=1960s)

孙宇晨说，中国是世界工厂，中国的产能、产品、想法卖到全世界都有机会。以前语言是最大的门槛，现在 AI 帮你翻译、帮你读外国论坛，门槛几乎没了。

一周下来，你手上会有一个验证过的海外需求。确实有人在抱怨这件事，你跟其中五个人聊过，还挂出了一个能收预约的落地页。

## 今天先试一次

1. 选一个你熟悉的行业，比如财务、教育、电商、设计。
2. 让 AI 去 Reddit 搜这个行业里抱怨最多的 10 个问题，翻译成中文给你。
3. 圈出一个你觉得自己能解决的。

## 接下来一周

| 天 | 做什么 |
| --- | --- |
| 1 | 在 3 个国家各找 10 条公开抱怨（Reddit、论坛、App 差评） |
| 2 | 选一个出现最多的问题，用一页纸写清楚你的解决方案 |
| 3 | 让 AI 把这页翻译成目标语言，再改得像当地人写的 |
| 4 | 做一个落地页：一句话价值 + 一个例子 + 一个预约按钮 |
| 5–6 | 找 5 个目标用户，每人聊 20 分钟：他现在怎么解决？愿意付多少钱？ |
| 7 | 看预约数和访谈记录，决定继续还是换一个问题 |

真有人想付钱了，再研究收款和注册公司。

## 用什么工具

| 用途 | 推荐 | 国内直接用 |
| --- | --- | --- |
| 看需求趋势 | [Google Trends](https://trends.google.com) | 百度指数（国内市场） |
| 看竞品流量 | [Similarweb](https://www.similarweb.com) | 同左，有免费数据 |
| 翻译、本地化 | [DeepL](https://www.deepl.com) + Claude | Kimi、通义 |
| 建站卖货 | [Shopify](https://www.shopify.com) | [店匠 Shoplazza](https://www.shoplazza.com) |
| 卖软件、订阅 | [Paddle](https://www.paddle.com)（帮你处理海外税） | — |
| 跨境收款 | [Wise Business](https://wise.com/business/) | [空中云汇](https://www.airwallex.com/cn)、[万里汇](https://www.worldfirst.com.cn) |

## 交给 AI 去搭

```
帮我找一个海外商机。我熟悉的行业是：【写在这里】，我会的语言是：【写在这里】。
1. 联网去 Reddit、行业论坛和 App 商店差评里，在美国、英国、东南亚各找 10 条这个行业的真实抱怨，附原文链接，翻译成中文。
2. 把抱怨按问题归类，告诉我出现最多的 3 个。
3. 针对我选的那个问题，写一页英文落地页文案：一句话价值、一个使用例子、一个预约按钮。
4. 给我一份 20 分钟的用户访谈提纲，重点问：他们现在怎么解决、花多少钱、最烦的是什么。
5. 告诉我去哪里能找到 5 个这样的用户。
全部存进 商机/【日期-行业】.md。
```
