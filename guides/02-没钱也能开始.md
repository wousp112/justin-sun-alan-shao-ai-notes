# 02 没钱也能开始，先拿免费额度练手

> 「我觉得多少钱都可以做，先把你的这个整套流程全部 AI 化。」
> —— 孙宇晨 [00:10:30](https://www.youtube.com/watch?v=0Z-vhBvBmUY&t=630s)

Claude Code 一个月 200 美元，孙宇晨自己也知道很多人用不起。他给的办法是先找个便宜的用着，把流程先 AI 化再说。贵的工具能让你快一点，可流程没理顺，换多贵的工具也没用。

做完以后，你每周都要做的某件麻烦事，以后跟 AI 说一句就办好了。你也会清楚它每周到底帮你省了多少分钟。

## 今天先试一次

1. 写下你每周至少做 3 次、每次超过 20 分钟的事。比如：整理会议记录、回复同类邮件、做周报。
2. 挑一件，把你平时怎么做的写成 5 句话。
3. 打开任何一个免费 AI，把这 5 句话和一份真实材料丢给它，说：「按这个流程帮我做一次。」
4. 结果能用，就把这 5 句话存成 `流程/【事情名】.md`，下次直接复制。

## 接下来一周

| 天 | 做什么 |
| --- | --- |
| 1 | 照上面做一次，记下花了几分钟 |
| 2–5 | 每次做这件事都用 AI，结果不对就改那 5 句话 |
| 6 | 把改好的流程交给 Agent，让它自动读文件夹、自动出结果 |
| 7 | 算一下：这周省了多少分钟？花了多少钱？省的时间不值，就停止付费 |

## 用什么工具

| 用途 | 推荐 | 国内直接用 |
| --- | --- | --- |
| 免费额度起步 | [Gemini CLI](https://geminicli.com)（个人登录有免费额度） | [Qwen Code](https://qwen.ai/qwencode)（CLI 免费，模型接阿里云百炼） |
| 便宜的 Agent 套餐 | [GLM Coding Plan](https://docs.z.ai/devpack/overview) | [Kimi Code](https://www.kimi.com/help/kimi-code/membership-guide)（49 元/月起） |
| 存流程 | Obsidian | [思源笔记](https://b3log.org/siyuan/) |

孙宇晨在访谈里点名的就是 Kimi Code 和 GLM。

## 交给 AI 去搭

```
我想用最少的钱把一件重复的事 AI 化。
1. 先问我：每周哪件事最烦、怎么做的、给我一份真实样本。
2. 把我的做法写成一个流程文件，存到 流程/【事情名】.md，写清楚输入是什么、输出是什么、怎么检查对不对。
3. 用这个流程处理我给的样本，让我检查。
4. 以后我说「跑一下【事情名】」，你就按流程文件执行。
5. 每次执行完在 流程/记录.md 里记一行：日期、花了几分钟、有没有出错。
```
