# 03 先升级操作系统，给自己建一个判断库

> 「第一个就是『孙学』，就是理论武装自己……『孙学』是一个大脑相当于升级，你操作系统总得换嘛。」
> —— 孙宇晨 [00:12:21](https://www.youtube.com/watch?v=0Z-vhBvBmUY&t=741s)

孙宇晨把对金钱、财富自由、万事万物的理解叫作操作系统，并且说它要不断升级。光听金句升级不了，要把判断写下来，拿资料去验证，被新证据推翻了就改。

做下来，你会攒出一个判断库。里面记着你对几件要紧事的看法，看法背后的资料，还有你哪天因为哪份资料改了主意。

## 今天先试一次

1. 新建文件夹 `判断库`，里面建 `资料` 和 `判断` 两个子文件夹。
2. 在 `判断` 里写一个文件，回答三个问题：
   - 我现在怎么看【某件事】？
   - 我凭什么这么看？
   - 看到什么证据我会改主意？
3. 让 AI 找 3 份支持你的资料、3 份反对你的资料，原文存进 `资料`。

## 接下来一周

| 天 | 做什么 |
| --- | --- |
| 1 | 写下第一个判断 |
| 2–4 | 每天往 `资料` 里加 2–3 份一手资料（原文、论文、官方数据） |
| 5 | 让 AI 只基于 `资料` 里的东西，给你的判断挑错 |
| 6 | 改写判断，旧版本保留，写清楚改了什么、为什么 |
| 7 | 开始第二个判断 |

## 交给 AI 去搭

```
帮我建一个判断库：
1. 在桌面建「判断库」，里面建 资料 和 判断 两个子文件夹。资料 里的原文不许改。
2. 问我一个我最近在想的问题，帮我写成 判断/【主题】.md：我的观点、依据、什么证据会让我改主意。
3. 联网找 3 份支持和 3 份反对的一手资料，原文保存到 资料/，每份写上来源链接和日期。
4. 只根据 资料/ 里的内容给我的判断挑错，每条都标出处。
5. 我改主意时，在判断文件底部追加一条记录：日期、旧看法、新看法、因为哪份资料。
```
