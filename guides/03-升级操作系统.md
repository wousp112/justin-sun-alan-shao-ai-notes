# 03 先升级操作系统

> 「第一个就是『孙学』，就是理论武装自己……『孙学』是一个大脑相当于升级，你操作系统总得换嘛。」
> —— 孙宇晨 [00:12:21](https://www.youtube.com/watch?v=0Z-vhBvBmUY&t=741s)

孙宇晨总结了三个理论，第一个就是「孙学」。他把对金钱、对财富自由、对万事万物的理解比作操作系统，隔一阵就要升级一次。

怎么升级，他没细说。我们的做法是把自己的看法写下来，找资料去对，碰到能推翻它的证据就改，改了留个记录。这样攒下来的东西，就是你自己的一套判断。

## 怎么做

1. 新建一个文件夹，叫 `判断库`，里面建 `资料` 和 `判断` 两个子文件夹。
2. 挑一件你最近一直在想的事，在 `判断` 里写下三句话：我现在怎么看，我凭什么这么看，看到什么我会改主意。
3. 让 AI 帮你找几份支持你的资料，再找几份反对你的，原文存进 `资料`。
4. 让 AI 只根据 `资料` 里的东西，给你的看法挑错。
5. 被说服了就改，旧的不要删，在下面写上改了什么、因为哪份资料。
6. 一个问题想清楚了，再开下一个。

## 用什么工具

| 用途 | 推荐 | 国内直接用 |
| --- | --- | --- |
| 存资料和判断，互相链接 | [Obsidian](https://obsidian.md) | [思源笔记](https://b3log.org/siyuan/) |
| 只根据你给的资料回答 | [NotebookLM](https://notebooklm.google) | Kimi 长文本 |
| 收藏网页和论文 | [Zotero](https://www.zotero.org) | Zotero 加坚果云同步 |
| 让 AI 把资料编成个人 Wiki | [Karpathy 的 LLM Wiki 方法](https://x.com/karpathy/status/2039805659525644595) | 用 Kimi Code 照着做 |

## 让 AI 帮你搭

```
帮我建一个判断库。
1. 在桌面建「判断库」，里面建 资料 和 判断 两个子文件夹。资料 里的原文不许改。
2. 问我一个我最近在想的问题，帮我写成 判断/【主题】.md，包括我的观点、依据、什么证据会让我改主意。
3. 联网找几份支持和几份反对的一手资料，原文保存到 资料/，每份写上来源链接和日期。
4. 只根据 资料/ 里的内容给我的判断挑错，每条都标出处。
5. 我改主意时，在判断文件底部追加一条记录：日期、旧看法、新看法、因为哪份资料。
```
