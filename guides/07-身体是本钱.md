# 07 身体是本钱

> 「还是碳基的时间是最关键的……千万不能下线，我们要超长待机……所以这个碳基这个第一位。」
> —— 孙宇晨 [01:00:10](https://www.youtube.com/watch?v=0Z-vhBvBmUY&t=3610s)

孙宇晨说他现在一天就干两件事，碳基和硅基，两边分配好。他把碳基排第一位，人不能「下线」。他自己戴 Oura Ring 抓睡眠和卡路里，训练拍视频，然后丢给 Claude Code 去整理。

这一篇帮你把身体数据接到 AI 那里，让它替你盯着趋势。具体记什么，看你在意什么，下面只是一个起点。

## 怎么做

1. 打开手机自带的健康 App，iPhone 就是「健康」，安卓用你手环的 App。
2. 截一张最近的睡眠和步数，丢给 AI，再加一句你最近精力怎么样，让它说说看到了什么。
3. 想长期记，可以先只盯几项，比如睡眠时长、静息心率、运动时长，再加一个你自己打的精力分。
4. 精力分每天找个固定的时候补一下，其他的交给手环自动记。
5. 攒了一段时间，把数据导出来给 AI，让它只看趋势，哪几项在变好，哪几项在变差。
6. 还想再往下做，可以把这些数据接进 [01 把生活 AI 化](01-生活AI化.md) 的日报里。

数据连续很不对劲的时候，直接去看医生。

## 用什么工具

| 用途 | 推荐 | 国内直接用 |
| --- | --- | --- |
| 睡眠和恢复 | [Oura Ring](https://ouraring.com)（孙宇晨在用）、[WHOOP](https://www.whoop.com) | [Zepp](https://www.zepp.com) 加 Amazfit、华为手环 |
| 运动手表 | [Garmin](https://connect.garmin.com) | Garmin 国行、华为 |

| 导出给 AI | [Health Auto Export](https://www.healthexportapp.com) | 手环 App 自带导出 |
| 力量训练记录 | [Hevy](https://www.hevyapp.com) | 训记、[Keep](https://www.gotokeep.com) |

## 让 AI 帮你搭

```
帮我搭一个身体记录系统。
1. 先问我用什么手机、什么手环或手表。
2. 告诉我怎么把睡眠、心率、运动数据定期导出成文件，放进 我的生活/素材/身体/。
3. 建一个 身体/精力.md，我每天补一行：日期、精力 1-10 分、一句话感受。
4. 我说「看看身体」，你就读最近的数据，只告诉我哪项在变好、哪项在变差、最值得改的一件事。
5. 数据出现连续明显异常时，直接提醒我去看医生。
```
