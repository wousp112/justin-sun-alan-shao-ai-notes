# 04 百分之百相信 AI，让它来掌舵

> 「百分之百相信 AI，好吧？百分之百相信 AI。」
> 「Claude 说什么我就执行，就是无论有多大阻力我都执行。」
> —— 孙宇晨 [00:15:46](https://www.youtube.com/watch?v=0Z-vhBvBmUY&t=946s)

很多人用 AI 只是问问，问完就放在那。孙宇晨正好反过来，他让 AI 掌舵，AI 说了他就去做。至于怎么问，他也说得很具体，同一个问题「问一下 Claude，问一下 OpenAI o1，问一下比如 GLM，三个，可以了」（[00:18:10](https://www.youtube.com/watch?v=0Z-vhBvBmUY&t=1090s)）。

这一篇想帮你养成一个习惯。遇到要紧的事，同一个问题问三个模型，挑出最好的方案，然后真的去做，做完把结果记下来。

## 今天先试一次

1. 想一件你拖了很久没决定的小事。
2. 把背景写清楚：你的情况、你的限制、你想要什么结果。
3. 把同一段话分别发给 3 个不同的 AI。
4. 挑出 3 个回答里都提到的那一步，今天就去做。

## 接下来一周

| 天 | 做什么 |
| --- | --- |
| 1 | 照上面做一次 |
| 2 | 建一个 `AI决策.md`，每次记下：问题、3 个 AI 怎么说、你选了哪个 |
| 3–6 | 每天至少一件事按 AI 的建议执行 |
| 7 | 回看这一周：哪个模型的建议最靠谱？下周主要问它 |

## 用什么工具

| 用途 | 推荐 | 国内直接用 |
| --- | --- | --- |
| 一次问多个模型 | [ChatHub](https://chathub.gg) | 分别打开 Kimi、通义、智谱清言 |
| 匿名对比模型 | [Arena](https://arena.ai) | 手动盲测：不看名字比较回答 |
| 统一入口切换模型 | [OpenRouter](https://openrouter.ai/chat) | 硅基流动 |
| 进阶：批量测哪个模型最适合你的任务 | [promptfoo](https://github.com/promptfoo/promptfoo) | 同左，接国内模型 API |

## 交给 AI 去搭

```
我要养成"问 AI → 执行"的习惯。
1. 建一个 AI决策.md，表头是：日期、问题、模型 A 建议、模型 B 建议、模型 C 建议、我选了什么、结果。
2. 现在问我一件拖着没决定的事，帮我把背景写成一段完整的提问。
3. 告诉我把这段话发给哪 3 个模型最合适（按我能用的工具来选），我把回答贴回来给你。
4. 你对比 3 个回答，告诉我共识是什么、分歧在哪、今天就该做的第一步是什么。
5. 记进 AI决策.md。一周后提醒我回来填结果。
```
