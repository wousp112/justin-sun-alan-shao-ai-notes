# 04 百分之百相信 AI

> 「百分之百相信 AI，好吧？百分之百相信 AI。」
> 「Claude 说什么我就执行，就是无论有多大阻力我都执行。」
> —— 孙宇晨 [00:15:46](https://www.youtube.com/watch?v=0Z-vhBvBmUY&t=946s)

孙宇晨说他现在让 AI 当掌舵者，Claude 说什么他就执行。至于怎么问，他讲得挺具体：「你可以问一下Claude，问一下……OpenAI o1，问一下比如GLM，三个，可以了」（[00:18:10](https://www.youtube.com/watch?v=0Z-vhBvBmUY&t=1090s)）。

这一篇就照这个来。同一个问题问三个模型，挑出最好的那个方案，然后去做，做完记下结果。记得多了，你自然会知道哪个模型在哪类问题上更靠谱。

## 怎么做

1. 想一件你一直拖着没定下来的事。
2. 把背景写清楚，包括你的情况、你的限制、你想要什么结果。
3. 把同一段话分别发给三个不同的 AI。
4. 三个回答都提到的那一步，先去做。
5. 建一个 `AI决策.md`，每次记一行：问的什么，三个 AI 各怎么说，你选了哪个，后来结果怎样。
6. 记得多了回头翻一翻，看哪个模型的建议最常被证明是对的。

## 用什么工具

| 用途 | 推荐 | 国内直接用 |
| --- | --- | --- |
| 一次问多个模型 | [ChatHub](https://chathub.gg) | 分别打开 Kimi、通义、智谱清言 |
| 匿名对比模型 | [Arena](https://arena.ai) | 自己盲测，不看名字比较回答 |
| 统一入口切换模型 | [OpenRouter](https://openrouter.ai/chat) | 硅基流动 |
| 批量测哪个模型最适合你的任务 | [promptfoo](https://github.com/promptfoo/promptfoo) | 同左，接国内模型 API |

## 让 AI 帮你搭

```
我想养成"同一个问题问三个 AI，然后去执行"的习惯。
1. 建一个 AI决策.md，表头是：日期、问题、模型 A 建议、模型 B 建议、模型 C 建议、我选了什么、结果。
2. 现在问我一件拖着没决定的事，帮我把背景写成一段完整的提问。
3. 告诉我把这段话发给哪 3 个模型最合适（按我能用的工具来选），我把回答贴回来给你。
4. 你对比 3 个回答，告诉我共识是什么、分歧在哪、现在就能做的第一步是什么。
5. 记进 AI决策.md。我回来告诉你结果时，帮我补上。
```
