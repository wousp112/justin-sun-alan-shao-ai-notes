# 14 缺啥补啥，去拿目标岗位的第一视角

> 「我跟所有人啊都是缺啥补啥。上班的人就不想上班。像我这个没上班的人啊，特别想上班。」
> —— 孙宇晨 [03:50:24](https://www.youtube.com/watch?v=0Z-vhBvBmUY&t=13824s)

孙宇晨一开始就创业，没怎么上过班，所以他特别想去 OpenAI、Anthropic 上班。原因是他「没有第一视角的信息」。看 JD、刷经验帖，都比不上亲手做一次。

做完以后，你会知道想去的那个岗位平时到底在忙什么，怎么考核，哪里最难。你还会有一份自己动手做的模拟作品，而且被真正干这行的人改过。

## 今天先试一次

1. 写下你想去的岗位。
2. 让 AI 写出这个岗位「真实的一天」：几点开会、做什么交付物、被什么考核。
3. 圈出 3 件你从来没亲手做过的事。

## 接下来一周

| 天 | 做什么 |
| --- | --- |
| 1 | 照上面做一次 |
| 2–3 | 找 2 个正在做这个岗位的人，各聊 20 分钟：实际产出、考核、最无聊的部分 |
| 4–5 | 做一个 2–4 小时的模拟任务，交付物用真实格式 |
| 6 | 请从业者按「能用 / 缺了什么 / 错了什么」批改 |
| 7 | 把最大的缺口变成接下来 4 周的一个学习项目 |

## 用什么工具

| 用途 | 推荐 | 国内直接用 |
| --- | --- | --- |
| 企业出题的模拟任务 | [Forage](https://www.theforage.com)（免费） | 牛客项目、企业公开案例 |
| 找从业者聊 | [ADPList](https://adplist.org)（免费） | 即刻、脉脉、V2EX |
| 付费导师批改 | [MentorCruise](https://mentorcruise.com) | 有作品的国内导师 |
| 整理访谈 | [Miro Empathy Map](https://miro.com/templates/empathy-map/) | 飞书白板 |

## 交给 AI 去搭

```
我想拿到目标岗位的第一视角。我想去的岗位是：【写在这里】。
1. 联网查这个岗位的真实 JD 和从业者分享，写出"真实的一天"：会议、交付物、考核指标。
2. 列出我最可能没做过的 3 件事。
3. 设计一个 2-4 小时能完成的模拟任务，交付物要用真实格式。
4. 给我一份 20 分钟的从业者访谈提纲，再告诉我去哪里能找到这样的人。
5. 我做完模拟任务后，你先按从业者的标准批改一遍。
存成 岗位探索/【岗位名】.md。
```
