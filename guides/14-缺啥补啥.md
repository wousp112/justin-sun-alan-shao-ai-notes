# 14 缺啥补啥

> 「我跟所有人啊都是缺啥补啥。上班的人就不想上班。像我这个没上班的人啊，特别想上班。」
> —— 孙宇晨 [03:50:24](https://www.youtube.com/watch?v=0Z-vhBvBmUY&t=13824s)

孙宇晨一开始就创业，没怎么上过班，所以他特别想去 OpenAI、Anthropic 上班。他说原因是自己「没有第一视角的信息」，不太了解别人上班到底是什么样。

想去一个岗位，也是一样的道理。看 JD、刷经验帖能知道个大概，亲手做一次才知道是什么滋味。这一篇帮你拿到这个第一视角。

## 怎么做

1. 写下你想去的岗位。
2. 让 AI 查一查这个岗位的真实 JD 和从业者分享，写出他们平时的一天，开什么会，交什么东西，怎么被考核。
3. 圈出几件你从来没亲手做过的事。
4. 找一两个正在干这行的人聊聊，问他们实际产出什么，怎么考核，最无聊的是哪部分。
5. 给自己出一道模拟题，做一份跟真实格式一样的交付物。
6. 请干这行的人帮你改一改，看哪些能用，缺了什么，哪里错了。
7. 改下来发现最大的缺口，就是你接下来要补的东西。

## 用什么工具

| 用途 | 推荐 | 国内直接用 |
| --- | --- | --- |
| 企业出题的模拟任务 | [Forage](https://www.theforage.com)（免费） | 牛客项目、企业公开案例 |
| 找从业者聊 | [ADPList](https://adplist.org)（免费） | 即刻、脉脉、V2EX |
| 付费导师批改 | [MentorCruise](https://mentorcruise.com) | 有作品的国内导师 |
| 整理访谈 | [Miro Empathy Map](https://miro.com/templates/empathy-map/) | 飞书白板 |

## 让 AI 帮你搭

```
我想拿到目标岗位的第一视角。我想去的岗位是【写在这里】。
1. 联网查这个岗位的真实 JD 和从业者分享，写出"真实的一天"，包括会议、交付物、考核指标。
2. 列出我最可能没做过的几件事。
3. 设计一个模拟任务，交付物要用真实格式，难度按我的水平来定。
4. 给我一份从业者访谈提纲，再告诉我去哪里能找到这样的人。
5. 我做完模拟任务后，你先按从业者的标准批改一遍。
存成 岗位探索/【岗位名】.md。
```
