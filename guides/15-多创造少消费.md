# 15 多创造，少消费，四周发四个作品

> 「你就应该去多创造，少消费。」
> 「多创造，少消费，然后你做什么基本上都是对的。」
> —— 孙宇晨 × 邵艾伦 [04:13:08](https://www.youtube.com/watch?v=0Z-vhBvBmUY&t=15188s)

刷 1 小时信息流是消费，把看到的东西变成一篇别人能用的教程是创造。孙宇晨也说，消费不用完全戒掉，它能帮你回血。但时间的大头要放在创造上。有了 AI，创造的门槛低了很多。经历和观点是你的，整理和表达可以交给 AI。

四周以后，你会发出去四个作品，可能是教程、清单、模板，也可能是小工具。每一个都有人真的用过，也给你提过意见。

## 今天先试一次

1. 想一个你这周刚解决的问题，比如装好了某个工具、搞懂了某个概念。
2. 打开 Agent，说：「我刚搞定了【这件事】，帮我写成一篇 500 字的新手教程，步骤要具体到点哪个按钮。」
3. 自己读一遍，改掉不像你说的话，然后发出去。

## 接下来一个月

| 周 | 产出 | 发到哪 |
| --- | --- | --- |
| 1 | 一篇 500 字教程 | X、即刻、小红书 |
| 2 | 一份清单或模板（比如「我的 AI 工具清单」） | GitHub 仓库 |
| 3 | 一个小工具或一段好用的 prompt | GitHub |
| 4 | 把前 3 周整理成一个合集页 | GitHub Pages 或公众号 |

这一个月只守一条规矩，每天先做 30 分钟东西，再去刷信息流。

## 交给 AI 去搭

```
帮我启动一个「4 周 4 个作品」计划。
1. 先问我：最近解决了什么问题、擅长什么、想发在哪个平台。
2. 根据我的回答，列出 4 个这个月能做的作品选题，每个写清楚：是什么、给谁用、要花几小时。
3. 在桌面建「作品」文件夹，每周一个子文件夹，放草稿和最终版。
4. 现在就帮我开始第 1 个：先让我口述经历，你整理成 500 字新手教程，步骤具体到点哪里、输入什么。保持我的说话风格，不要写成官方腔。
```
