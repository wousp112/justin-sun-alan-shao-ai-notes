# 00 准备：装一个能操作你电脑的 AI

后面每篇教程的最后，都有一段可以直接复制给 AI 的话。你需要一个能读写你电脑文件的 AI，也就是 Agent。网页版聊天 AI 只能聊天，碰不到你的文件。

孙宇晨在访谈里说得很直接：用不起贵的，就先用便宜的，先把整套流程 AI 化。

## 手把手（以 Mac 为例）

1. 按 `Command + 空格`，输入「终端」，回车。
2. 打开上表里你选的工具的官网，复制官网给的安装命令，粘贴到终端，回车。
3. 安装完，在终端输入工具名回车，例如 `claude` 或 `codex`，按提示登录。
4. 看到它问你「要做什么」，就装好了。

Windows 用户：按 `Win` 键，搜「PowerShell」，其余步骤一样。

## 试一下

把这句话发给它：

```
在我的桌面新建一个文件夹叫 AI实验室，在里面写一个 README.md，内容是今天的日期和一句"我开始了"。
```

桌面上出现这个文件夹，就说明它能操作你的电脑了。接下来随便挑一篇教程开始。
