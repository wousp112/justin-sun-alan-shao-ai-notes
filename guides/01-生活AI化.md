# 01 把生活 AI 化：7 天搭一个个人日报系统

> 「全部 AI 化……可视化、数据化，然后可总结化。全部都搞了这个 MD 文档，照片也全部都保存了……下一个 AI 来就直接读……换 Codex 也可以直接来。」
> —— 孙宇晨 [00:06:53](https://www.youtube.com/watch?v=0Z-vhBvBmUY&t=413s)

## 做完你会得到

一个文件夹。你每天往里丢照片、语音、几句话，AI 每晚给你一份日报，每周一份周报。换任何 AI，都能 5 分钟读懂你的过去一周。

## 为什么这么做

AI 给你的建议，好坏取决于它对你了解多少。孙宇晨的做法是把饮食、训练、睡眠全部交给 AI 记录，资料存成普通文件。文件是你的，换工具也不丢。

## 15 分钟上手

1. 在桌面新建文件夹 `我的生活`，里面再建三个文件夹：`收件箱`、`日报`、`素材`。
2. 今天吃饭前拍一张照片，存进 `素材`。
3. 打开 `收件箱`，新建一个文本文件，写三句话：今天干了什么、精力怎么样（1–10 分）、有什么想法。
4. 打开你的 Agent，说：「读 `我的生活` 文件夹，给我写今天的日报。」

## 7 天版

| 天 | 只加一个动作 |
| --- | --- |
| 1 | 照上面做一次 |
| 2 | 加睡眠：早上起来记几点睡、几点醒 |
| 3 | 加运动：练了什么，拍一段视频也行 |
| 4 | 加工作：今天最重要的一件事做完没有 |
| 5 | 让 AI 把日报格式固定下来，写进 `README.md` |
| 6 | 接上手环或手表的数据导出（见下表） |
| 7 | 让 AI 写周报：这周什么变好了，什么变差了，下周改一件事 |

第 8 天换一个 AI，让它读这个文件夹。它能直接接着写，系统就搭成了。

## 工具

| 用途 | 推荐 | 国内直接用 |
| --- | --- | --- |
| 存文件、看文件 | [Obsidian](https://obsidian.md)（免费） | [思源笔记](https://b3log.org/siyuan/)（免费） |
| 读文件、写日报 | Claude Code / Codex | Kimi Code / Qwen Code |
| 睡眠和活动 | [Oura Ring](https://ouraring.com)（孙宇晨在用） | [Zepp](https://www.zepp.com) + Amazfit、华为手环 |
| 健康数据导出 | [Health Auto Export](https://www.healthexportapp.com)（iPhone） | 手环 App 自带导出 |
| 语音和照片自动记录 | [Remember This](https://rememberthis.ai/docs)（Mac） | 手机录音 + 相册，手动丢进 `收件箱` |

## 丢给 Agent 的话

复制下面整段，发给你的 Agent：

```
帮我搭一个个人日报系统：
1. 在我的桌面建文件夹「我的生活」，里面建 收件箱、日报、素材 三个子文件夹，再写一个 README.md 说明每个文件夹放什么。
2. 设计一个日报模板，包括：今天做了什么、精力 1-10 分、睡眠、运动、一个想法。保存成 日报/模板.md。
3. 以后我说「写日报」，你就读 收件箱 和 素材 里今天的新东西，按模板生成 日报/YYYY-MM-DD.md，每条结论标出来自哪个文件。
4. 我说「写周报」，你就读这周的日报，告诉我什么变好了、什么变差了、下周只改一件事。
5. 先问我用什么手机和手环，再告诉我怎么把睡眠数据自动导出到 素材 文件夹。
做完给我看文件结构。
```
