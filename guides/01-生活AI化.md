# 01 把生活 AI 化

> 「全部 AI 化……可视化、数据化，然后可总结化。全部都搞了这个 MD 文档，照片也全部都保存了……下一个 AI 来就直接读……换 Codex 也可以直接来。」
> —— 孙宇晨 [00:06:53](https://www.youtube.com/watch?v=0Z-vhBvBmUY&t=413s)

孙宇晨刚开始练搏击，他的做法是饭前饭后拍照，训练录视频，睡眠交给 Oura Ring，然后统统丢给 Claude Code，让它每天整理一份。东西都存成普通文件，所以换一个 AI，也能接着读。

照这个思路，你可以给自己搭一个文件夹，平时往里丢照片和几句话，让 AI 帮你整理成日报。攒得久了，AI 对你越来越了解，给的建议也会越来越贴身。

## 怎么做

1. 在桌面新建一个文件夹，叫 `我的生活`，里面再建三个：`收件箱`、`日报`、`素材`。
2. 吃饭前拍一张照片，存进 `素材`。
3. 在 `收件箱` 里新建一个文本文件，随手写几句，今天干了什么，精力怎么样，想到了什么。
4. 打开你的 Agent，跟它说「读一下 `我的生活` 这个文件夹，帮我写今天的日报」。
5. 觉得有用，就慢慢往里加别的，睡眠、运动、工作都可以。加什么、加多少，看你自己。
6. 日报格式用顺手了，让 AI 把它写进 `README.md` 固定下来。
7. 攒了一阵子以后，让 AI 回头看看这段时间什么变好了，什么变差了。

想检验这套东西搭没搭成，可以换一个 AI 来读这个文件夹。它能直接接着写下去，就说明成了。

## 用什么工具

| 用途 | 推荐 | 国内直接用 |
| --- | --- | --- |
| 存文件、看文件 | [Obsidian](https://obsidian.md)（免费） | [思源笔记](https://b3log.org/siyuan/)（免费） |
| 读文件、写日报 | Claude Code / Codex | Kimi Code / Qwen Code |
| 睡眠和活动 | [Oura Ring](https://ouraring.com)（孙宇晨在用） | [Zepp](https://www.zepp.com) + Amazfit、华为手环 |
| 健康数据导出 | [Health Auto Export](https://www.healthexportapp.com)（iPhone） | 手环 App 自带导出 |
| 语音和照片自动记录 | [Remember This](https://rememberthis.ai/docs)（Mac） | 手机录音加相册，手动丢进 `收件箱` |

## 让 AI 帮你搭

把下面这段整个复制给你的 Agent。

```
帮我搭一个个人日报系统。
1. 在我的桌面建文件夹「我的生活」，里面建 收件箱、日报、素材 三个子文件夹，再写一个 README.md 说明每个文件夹放什么。
2. 设计一个日报模板，包括今天做了什么、精力 1-10 分、睡眠、运动、一个想法。保存成 日报/模板.md。
3. 以后我说「写日报」，你就读 收件箱 和 素材 里新加的东西，按模板生成 日报/YYYY-MM-DD.md，每条结论标出来自哪个文件。
4. 我说「回顾一下」，你就读最近的日报，告诉我什么变好了、什么变差了、接下来最值得改的一件事。
5. 先问我用什么手机和手环，再告诉我怎么把睡眠数据自动导出到 素材 文件夹。
做完给我看文件结构。
```
