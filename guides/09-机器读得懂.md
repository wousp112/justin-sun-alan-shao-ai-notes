# 09 机器读得懂才值钱：把 10 份旧资料变成 AI 能读的文件

> 「AI 只能读得懂机器读得懂的东西。」
> 「你必须把它形式化了……让计算机读懂了，才算是消化。」
> —— 孙宇晨 [01:33:10](https://www.youtube.com/watch?v=0Z-vhBvBmUY&t=5590s)

## 做完你会得到

10 份你最常用的资料（扫描 PDF、截图、Word、表格），全部变成 AI 一读就懂的 Markdown 文件。以后问 AI 任何相关问题，它都能直接引用原文回答。

## 为什么这么做

你电脑里大部分资料，AI 其实读不了：扫描件是图片，表格乱七八糟，截图里的字复制不出来。这些资料不转换，AI 再强也帮不上你。这一步是后面所有教程的地基。

## 15 分钟上手

1. 在桌面新建文件夹 `资料库`，里面建两个文件夹：`原件` 和 `可读版`。
2. 挑 1 份最常用的 PDF，复制进 `原件`。
3. 打开你的 Agent，说：「把 `资料库/原件` 里的 PDF 转成 Markdown，放进 `可读版`。」
4. 打开转出来的文件，随便挑 3 个数字和原件对一下。对得上，就成功了。

## 进阶：一次转 10 份

1. 把最常用的 10 份资料都放进 `原件`。原件只放不改。
2. 让 Agent 批量转换，每个文件开头写上：来源文件名、日期、用了什么工具。
3. 每份抽查 3 个数字或人名。错得多的那份，换工具重新转。
4. 让 Agent 在 `资料库` 写一个 `README.md`，列出每份资料讲什么。下次任何 AI 进来，先读这个目录。

## 工具

| 资料类型 | 推荐 | 说明 |
| --- | --- | --- |
| 普通 PDF、Word、PPT、Excel | [MarkItDown](https://github.com/microsoft/markitdown) | 微软开源，免费，一行命令转换 |
| 中文复杂 PDF、公式、表格 | [MinerU](https://github.com/opendatalab/MinerU) | 国内团队开源，中文效果好 |
| 扫描版 PDF | [OCRmyPDF](https://github.com/ocrmypdf/OCRmyPDF) | 给扫描件加上可复制的文字层 |
| 乱七八糟的表格 | [OpenRefine](https://github.com/OpenRefine/OpenRefine) | 可视化清洗重复值和格式错误 |
| 查看转换结果 | [Obsidian](https://obsidian.md) / [思源笔记](https://b3log.org/siyuan/) | 都免费 |

以上全部免费开源，在本机运行，资料不上传。国内外都能用。

## 丢给 Agent 的话

```
帮我把旧资料变成 AI 能读的文件：
1. 在桌面建「资料库」文件夹，里面建 原件 和 可读版 两个子文件夹。原件里的文件永远不许修改。
2. 检查我电脑有没有 Python，没有就帮我装。然后安装 MarkItDown（pip install 'markitdown[all]'）。
3. 把 原件 里每个文件转成 Markdown，放进 可读版。每个文件开头写：原文件名、转换日期、用的工具。
4. 如果是扫描件或中文复杂 PDF，MarkItDown 转出来乱码，就改用 MinerU 或 OCRmyPDF，装之前先告诉我。
5. 每份文件随机抽 3 个数字或专有名词和原件核对，把核对结果列给我。
6. 在 资料库 写一个 README.md，一行一份资料，说明它讲什么。
```
