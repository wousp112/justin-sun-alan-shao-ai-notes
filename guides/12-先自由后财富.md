# 12 先自由，后财富：算出你的自由线

> 「财富自由啊，其实还是先自由，后财富。得先自由了，财富啊，它是一个伴生品。」
> 「你拿到自由之后，财富是你自由之后呢伴生的一个后果。」
> —— 孙宇晨 [02:43:35](https://www.youtube.com/watch?v=0Z-vhBvBmUY&t=9815s)

## 做完你会得到

三个数字：你每月最低要花多少、你需要多少缓冲金、你每周有多少时间是自己说了算的。外加一个让这三个数字慢慢变好的计划。

## 为什么这么做

孙宇晨说这是他比 2016 年讲得更深刻的版本：先自由，财富是伴生品。认知不变，突然拿到一大笔钱也留不住。所以第一步是让自己有选择权：少被固定支出绑住，多一些自己能支配的时间。

## 15 分钟上手

1. 打开支付宝或微信账单，看上个月花了多少。
2. 分成三类：活下去必须的、承诺了的（房租、订阅、贷款）、可以砍的。
3. 让 AI 帮你算：必须支出 × 3 = 你的缓冲金目标。

## 7 天版

| 天 | 做什么 |
| --- | --- |
| 1 | 导出上个月账单，让 AI 分好三类 |
| 2 | 算出缓冲金目标，以及离目标还差多少 |
| 3 | 砍掉一个可以砍的订阅或固定支出 |
| 4–6 | 记录每天的时间：哪些是自己定的，哪些是别人定的，哪些是被刷手机吃掉的 |
| 7 | 把砍下来的钱存进缓冲金，把省下来的时间留给一项能带走的技能 |

## 丢给 Agent 的话

```
帮我算出我的自由线。
1. 告诉我怎么从支付宝、微信或银行导出上个月的账单，我导出后放进 财务/账单/。
2. 读账单，把支出分成三类：必须的、承诺的、可以砍的。做成一张表。
3. 算出：每月最低支出、3 个月缓冲金目标、现在离目标还差多少。
4. 从"可以砍的"里，推荐 3 项最值得砍的。
5. 存成 财务/自由线.md，每个月初提醒我更新一次。
```
