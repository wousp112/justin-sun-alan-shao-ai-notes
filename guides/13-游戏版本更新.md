# 13 游戏版本会更新

> 「每个大版本地球也会更新。你这个版本就削弱房地产，你前面房地产强，后面削弱，AI 又加强啊。」
> —— 孙宇晨 [02:33:57](https://www.youtube.com/watch?v=0Z-vhBvBmUY&t=9237s)

孙宇晨拿打游戏打比方，上个版本最强的打法，换了版本可能就不灵了。AI 是这一版被加强的，他也说不准再过十年会不会被削弱。

能做的，是比别人早一点看到版本要变。这一篇帮你搭一个小雷达，只装少量一手信息源，让 AI 替你看哪里在变。

## 怎么做

1. 想一想你这一行有哪些「版本信号」，比如招聘多了还是少了，头部公司发了什么，有什么新政策，客户预算怎么变，开源项目活不活跃。
2. 每个信号找一两个一手来源，官方博客、公司公告、GitHub 仓库都算。
3. 全部订阅进一个 RSS 阅读器，那些只会转述别人的号可以取关了。
4. 有空就翻一翻，觉得有意思的收藏起来。
5. 收藏攒到一定数量，丢给 AI，让它写一页「版本更新」，什么变强了，什么变弱了，你手上哪件事该停了。

新工具出来，可以先花一两个小时试试，好用再搬，不用看到热度就全换。

## 用什么工具

| 用途 | 推荐 | 国内直接用 |
| --- | --- | --- |
| RSS 阅读器 | [Folo](https://github.com/RSSNext/Folo)（开源） | Folo |
| RSS 付费版 | [Inoreader](https://www.inoreader.com) | Folo |
| 看开源新趋势 | [GitHub Trending](https://github.com/trending) | 同左 |

| 技术周报 | [TLDR](https://tldr.tech) | InfoQ、极客公园 |
| AI 工具合集 | [Awesome MCP Servers](https://github.com/punkpeye/awesome-mcp-servers)、[Awesome Claude Code](https://github.com/hesreallyhim/awesome-claude-code)、[Awesome Agent Skills](https://github.com/VoltAgent/awesome-agent-skills) | 同左 |

## 让 AI 帮你搭

```
帮我搭一个版本更新雷达。
1. 问我在哪个行业、关心什么方向。
2. 帮我列出这个方向的几个版本信号，每个推荐 1-2 个一手信息源（官方博客、GitHub、公司公告），给出 RSS 地址。
3. 告诉我怎么在 Folo 里导入这些源。
4. 我把收藏的条目发给你，你就写一页 雷达/【日期】.md：什么加强了、什么削弱了、我该开始做什么、停止做什么。
```
