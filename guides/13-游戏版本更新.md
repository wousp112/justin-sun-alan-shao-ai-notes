# 13 游戏版本会更新，给自己装个雷达

> 「每个大版本地球也会更新。你这个版本就削弱房地产，你前面房地产强，后面削弱，AI 又加强啊。」
> —— 孙宇晨 [02:33:57](https://www.youtube.com/watch?v=0Z-vhBvBmUY&t=9237s)

孙宇晨拿打游戏打比方，上个版本最强的打法，换了版本可能就不灵了。AI 是这一版被加强的，再过十年，说不定也会被削弱。你能做的，是比别人早一点看到版本要变。

搭好的雷达里只放十个一手信息源。每到周末，AI 替你写一页更新说明，讲清楚这周什么变强了，什么变弱了，你手上哪件事该停了。

## 今天先试一次

1. 写下你所在行业的 5 个「版本信号」，比如：招聘数量、头部公司发布了什么、政策、客户预算、开源项目活跃度。
2. 每个信号找 2 个一手来源：官方博客、公司更新、GitHub 仓库。
3. 全部订阅进一个 RSS 阅读器。

## 接下来一周

| 天 | 做什么 |
| --- | --- |
| 1 | 装好 RSS 阅读器，订阅 10 个一手源 |
| 2 | 取关那些只会转述别人的信息流号 |
| 3–6 | 每天花 15 分钟看 RSS，有意思的条目收藏 |
| 7 | 把收藏丢给 AI，写一页「本周版本更新」：加强了什么、削弱了什么、我停止做什么 |

新工具出来，先花 60 分钟试一下，好用再迁移，不要一看到热度就全部换掉。

## 用什么工具

| 用途 | 推荐 | 国内直接用 |
| --- | --- | --- |
| RSS 阅读器 | [Folo](https://github.com/RSSNext/Folo)（开源） | Folo |
| RSS 付费版 | [Inoreader](https://www.inoreader.com) | Folo |
| 看开源新趋势 | [GitHub Trending](https://github.com/trending) | 同左 |
| 看新产品 | [Product Hunt](https://www.producthunt.com) | 少数派、即刻 |
| 技术周报 | [TLDR](https://tldr.tech) | InfoQ、极客公园 |
| AI 工具合集 | [Awesome MCP Servers](https://github.com/punkpeye/awesome-mcp-servers)、[Awesome Claude Code](https://github.com/hesreallyhim/awesome-claude-code)、[Awesome Agent Skills](https://github.com/VoltAgent/awesome-agent-skills) | 同左 |

## 交给 AI 去搭

```
帮我搭一个版本更新雷达。
1. 问我在哪个行业、关心什么方向。
2. 帮我列出这个方向的 5 个版本信号，每个推荐 2 个一手信息源（官方博客、GitHub、公司公告），给出 RSS 地址。
3. 告诉我怎么在 Folo 里导入这些源。
4. 每周日我把收藏的条目给你，你写一页 雷达/【日期】.md：本周加强了什么、削弱了什么、我该开始做什么、停止做什么。
```
