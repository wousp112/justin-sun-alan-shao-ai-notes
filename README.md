## 每篇教程长什么样

1. **原话**：孙宇晨怎么说的，附视频时间点
2. **做完你会得到**：一个看得见的成品
3. **15 分钟上手**：今天就能做完
4. **7 天版**：每天只加一个动作
5. **工具**：推荐和国内两条路并排
6. **丢给 Agent 的话**：复制给你的 AI，它帮你装好、建好
